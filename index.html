Step 01 — Source Meshes

Start with your source meshes.

Choose one or more mesh sources and define how much influence each one should have. This is the heart of the system: instead of manually duplicating objects, you decide what gets scattered and how much of each source appears.

The independent Amount value for every source makes it easy to blend different assets together and build more organic, less repetitive results.

Step 02 — Four Scatter Modes

One tool.
Four ways to draw.

Surface Pencil gives you multiple ways to define where assets should appear. As you continue to scroll, the highlight travels across the mode buttons and the explanation updates from Area to Path, Brush, and finally Whole Mesh.

Step 03 — Wire Box Preview

Stay fast.
Preview light.

When scene density rises, Wire Box Preview helps you keep the viewport manageable. It offers a lighter visual representation so you can continue working, iterating, and placing assets without carrying the full display cost of every instance.

Red Mode Highlight: the page theme shifts to match the UI button, creating a stronger contrast and drawing attention to this performance-focused feature.
This section is ideal for showing how Surface Pencil remains practical not only for placement, but also for keeping complex environments easier to navigate while you build them.
